양식을 받아 학생 명단·좌석 배열·조건을 입력한 뒤 올리면 아래 모든 설정이 채워집니다. 현재 설정을 엑셀로 내보내 수정한 뒤 다시 올릴 수도 있어요.

엑셀 작성 방법 보기
  • 학생명단 : 이름 / 성별(남·여). 번호는 위에서부터 1, 2, 3… 자동으로 매겨지며, 다른 시트에서 학생을 적을 때는 이 번호나 이름 중 편한 쪽을 쓰세요.
  • 좌석배열 : 위쪽 행이 교탁에 가까운 앞쪽 행, 왼쪽이 학생이 앉아서 본 왼쪽. 책상이 있는 칸은 1, 빈 칸·통로는 0
  • 모둠 : 좌석배열과 같은 크기의 표에 모둠 번호를 적습니다 (모둠 배치를 쓸 때만, 없는 칸은 0)
  • 붙이기 / 떼기 : 두 학생 (붙이기는 방식 좌우/주변, 떼기는 최소 반경 칸 수 — 비우면 2칸). 모둠 배치에서는 붙이기 = 같은 모둠, 떼기 = 다른 모둠
  • 고정석 : 학생 / 행 / 열 — 통로를 뺀 번호입니다 (행 1 = 맨 앞 행, 열 1 = 맨 왼쪽)
  • 범위 : 학생 / 시작행 / 끝행 / 시작열 / 끝열 — 같은 학생을 여러 줄 적으면 합쳐서 적용
  • 이전짝 : 예전에 짝(또는 같은 모둠)이었던 두 학생 — 앱에서 확정할 때마다 자동으로 쌓입니다
